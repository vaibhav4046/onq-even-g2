Overview & Core Capabilities

Default-NO Ring Safety

External writes and messages are staged first and only committed after an explicit R1 ring tap (YES) or operator confirmation; double-tap cancels or returns to the corridor.

Universal AI Orchestrator

1-click model routing across OpenRouter / ChatGPT / Claude, Local CLIs, and deterministic Rules with automatic quota cooldown failover.

Self-Harnessing 24/7 Proactive Agent

Continuously synthesizes Code-Guard-verified 42-column corridor plans and pushes them to G2 over SSE strictly behind Default-NO staging.

Code-Guard Fact Verification

Deterministic fact verification cross-checks generated replies and briefs against source context before committing or displaying on G2.

Security & Local-First Architecture

OnQ runs locally on your own computer over loopback (127.0.0.1:8787). OAuth credentials, refresh tokens, and connector API keys are stored strictly on your device inside an AES-256-GCM encrypted vault with 0600 file permissions. OnQ does not operate any central cloud token database or sell user data.
